# chordbuilder

Build printable 5-string banjo chord charts. Open `index.html` in a browser; there's nothing to install and it works offline.

## Using it

- **Editor:** click a fret to place a dot. Click the dot again to remove it, or pick a different finger (1–4, T) and click it to relabel it. Click above the nut to switch a string between open (○) and muted (×). The **Barre** tool takes two clicks on the same fret.
- **Chord name:** filled in from the notes you place (G, Am, D7, …). Type your own name to override it.
- **Chord library:** pick a root and chord type to see playable voicings for the current tuning, easiest first. Click one to load it into the editor.
- **Quick start:** adds a whole set of chords to the sheet in one click, e.g. "Key of G basics".
- **Sheet:** click a chart to edit it, then press **Save changes**. Hover a chart to move, duplicate or delete it. **Print** prints only the sheet: white background, black ink.
- **Save file / Open file:** save a sheet as JSON and open it again later. The sheet is also kept in your browser between visits.
- **SVG / PNG:** download the chart that's in the editor.

Tunings: Open G (gDGBD), Double C, Open C, G Modal, Open D and Open A.

The 5th string only starts at the 5th fret. It's drawn dashed above that point, and you can only fret it from fret 6 up. You can switch the dashed drawing off with the "Short 5th string" option.

Fingerings for library chords come from a simple rule of thumb and won't always match how you play. Change any label by clicking the dot.
